# API Users, аналог работы с СУБД(1)
#### Что бы это работало установи node, после скачай файл Node.js, открой терминал и в нем перейди в эту папку, после напиши npm -init, нажимай пробел пока непояится подтверждения создания файла package.json, вставь в него
#### {
####   "name": "00", это не важно, главное что бы не было пустым и не только пробелы
####   "version": "1.0.0",
####   "description": "",
####   "scripts": {
####     "start": "nodemon ./server.js"
####   },
####   "author": "Makar Star",
####   "license": "ISC",
####   "devDependencies": {
####     "nodemon": "^3.1.14"
####   },
####   "dependencies": {
####     "body-parser": "^2.2.2",
####     "express": "^5.2.1"
####   }
#### } и нажми Ctrl + S, после в терминале введи npm i и жди установки, после установки введи npm run start и используй следующие функции:
### Что бы добавить пользователя перейди на сайт http:localhost:2000/users/addUser/name=имяПользователя(строка)&age=возрастПользователя(число)&isDelete=удаленЛиПользователь(true или false)
### Что бы обновить данные пользователя перейди на сайт http:localhost:2000/users/update/id=айдиПользователяУКоторогоХотитеИзменитьДанные(число)&name=имяПользователя(строка)&age=возрастПользователя(число)&isDelete=удаленЛиПользователь(true или false)
### Что бы удалить пользователя перейди на сайт http:localhost:2000/users/delete/id=айдиПользователяКоторогоХотитеУдалить(число)
### Что бы получить одного пользователя по id перейди на сайт http:localhost:2000/users/id=айдиПользователяКоторогоХотитеПолучить(число)
